### ✅ Реализованный функционал:

1. **Telegram-бот с AI-персонажем "Гена Валет"**
   - Интеграция с GPT-4o-mini (OpenAI)
   - Уникальный системный промпт для характера персонажа

4. **Платёжная система**
   - Готовая интеграция CryptoBot (USDT)
   - Демо-режим для тестирования без реальных платежей

5. **Администрирование**
   - Команда `/admin` со статистикой
   - Защита по Telegram ID

6. **Docker-контейнеризация**
   - `docker-compose.yml` — запуск одной командой
   - `Dockerfile` — готовый образ

## 🚀 Как запустить (для клиента)

### Вариант 1: Docker (рекомендуется)

```bash
# 1. Скопировать пример переменных
cp .env.example .env

# 2. Отредактировать .env (открыть в любом текстовом редакторе)
#    - TELEGRAM_TOKEN: токен от @BotFather
#    - OPENAI_API_KEY: ключ от platform.openai.com
#    - ADMIN_IDS: ваш Telegram ID (узнать через @userinfobot)

# 3. Запустить
docker-compose up -d --build

# 4. Проверить логи
docker-compose logs -f bot
```

### Вариант 2: Локально (Python)

```bash
# 1. Установить Python 3.11+ и PostgreSQL

# 2. Создать БД:
sudo -u postgres psql
CREATE DATABASE gena_valet_bot;
CREATE USER gena_user WITH PASSWORD 'gena_password_secure_123';
GRANT ALL PRIVILEGES ON DATABASE gena_valet_bot TO gena_user;

# 3. Установить зависимости:
pip install -r requirements.txt

# 4. Настроить .env и запустить:
python gena_valet_bot.py
```
